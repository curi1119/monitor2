# 使用方法と設定

Windows x64用のmonitor2.exeを実行します。枠の任意の場所をドラッグして移動し、右クリックで「設定」「終了」を選べます。通知領域のメニューからも操作できます。

通常起動・プレビューの二重起動は防止し、2つ目はそのまま終了します。同じユーザーの別のログインセッションや別フォルダのEXEも対象です。設定画面はEscapeでも閉じられ、変更を保存せずに戻ります。

設定の保存時に画面へ反映します。

- 常に手前に表示する: 初期値オン。
- Windows起動時に起動する: 初期値オフ。現在のユーザーのログイン時に起動します。HKCUのRunキーにmonitor2を登録します。実行ファイルを移動したときは設定を保存し直してください。
- 監視インターバル: 初期値1秒。0.25〜60秒を指定できます。
- コア表示: 論理コアすべて（初期値）／物理コアのみ。物理コアの使用率は、そのコアに属する論理CPU使用率の平均です。
- コア使用率%: 初期値オフ。バーは常に表示します。
- CPU番号（00〜）: 初期値オン。非表示にすると、その分バーを広く表示します。

設定保存先は `%LOCALAPPDATA%\monitor2\settings.ini`。メモリ表示のGはGiB（1024の3乗バイト）です。

ウィンドウの位置はドラッグ終了時と終了時に自動保存し、次回起動時に復元します。設定画面で保存する必要はありません。未保存の場合は従来の初期位置（X=40、Y=80）を使います。モニターの取り外し・解像度変更などで画面外になる場合は、最寄りのモニターの作業領域内へ補正します。座標は画面上のピクセル単位で、左側・上側のモニターの負の座標も保存できます。通常起動とプレビューで位置を共有し、`--smoke-test`では位置を保存しません。

画面は140 DIP幅、16論理コア・GPU1台の場合280 DIP高です。DPI倍率に応じて拡大し、多数のコア／GPUではスクロールします。NVIDIA GPUはドライバー付属NVMLから取得し、未対応や取得失敗はN/Aで表示します。CPU温度は今回の対象から延期しました。

CPU・RAMと各GPUは個別の角丸パネルとして表示し、パネル間の2 DIPの隙間は透過します。各パネルから画面全体をドラッグできます。隙間へのクリックは背後のウィンドウへ通ります。

更新が監視間隔の3倍（最低3秒）以上止まった場合は数値をN/Aにします。取得失敗やSTALEの詳細は通知領域のアイコンにマウスを置いて確認できます。
