monitor2
Windows x64用 CPU・メモリ・NVIDIA GPUモニター

使い方
  ZIPを展開し、monitor2.exeを実行してください。
  画面をドラッグすると移動できます。
  右クリックで「設定」「終了」を選択できます。
  通知領域のアイコンからも操作できます。

設定
  ・常に手前に表示する（初期値: オン）
  ・Windows起動時に起動する（初期値: オフ。ログイン時に起動）
  ・監視インターバル（初期値: 1秒。0.25〜60秒）
  ・物理コアのみ／論理コアすべて（初期値: 論理コアすべて）
  ・コア使用率%の表示（初期値: オフ）
  ・CPU番号の表示（初期値: オン）
  保存するとすぐに反映されます。
  設定保存先: %LOCALAPPDATA%\monitor2\settings.ini
  実行ファイルを移動した場合、自動起動の設定を保存し直してください。

表示について
  メモリのGはGiB（1,073,741,824バイト）です。
  物理コアの使用率は、そのコアに属する論理CPU使用率の平均です。
  NVIDIA GPUの取得には対応するNVIDIAドライバーが必要です。
  取得できない値や更新が止まった値はN/Aで表示します。
  詳細なエラーは通知領域のアイコンにマウスを置いて確認できます。
  CPU温度には現在対応していません。
