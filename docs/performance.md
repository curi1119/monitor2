# 旧版と初版試作の性能比較

2026-10-01に同じ実機上で同時測定しました。
最終試作版の起動時動作と参照寿命を修正した後、再測定した結果です。

## 条件

- CPU: AMD Ryzen 7 5800X3D、16論理CPU。
- GPU: NVIDIA GeForce RTX 4070 Ti、ドライバー616.56。
- 旧版: 起動済みのMonitor、PID 20724、C:\Monitor.exe。
- 試作: Rust 1.98.1のreleaseビルド、通常の常駐モード、PID 10900。
- 両アプリとも約1秒更新。試作版は起動後10秒待ってから測定。
- 2026-10-01 07:22:11 JST開始、120.975秒、2秒間隔で61サンプル。
- 画面操作ツールが試作に干渉しない状態で測定。旧版は終了・再起動していない。
- 実行ファイル: 249,856 bytes（244 KiB）。
- 試作実行ファイルSHA-256: E120D6E3A99DF2AE755D22FE83754CE3E2F98899BA3E755E18B9F41F26C48419

## 結果

| 指標 | 旧版 Monitor | monitor2試作 | 試作の変化 |
|---|---:|---:|---:|
| 測定区間のCPU時間 | 0.625秒 | 0.250秒 | 約60%減 |
| 平均CPU使用率（1論理CPU=100%） | 0.5166% | 0.2067% | 約60%減 |
| 平均CPU使用率（16論理CPU全体=100%） | 0.0323% | 0.0129% | 約60%減 |
| 平均Working Set | 49.745 MiB | 42.716 MiB | 約14%減 |
| 平均Private Bytes | 46.753 MiB | 27.436 MiB | 約41%減 |
| Private Bytes開始→終了 | 46.750→46.750 MiB | 27.508→27.359 MiB | 区間中に増加せず |
| ハンドル数開始→終了 | 568→568 | 250→248 | 増加せず |

CPU使用率は、プロセスのTotalProcessorTimeの差を実測時間で割って計算しています。
CPU時間はカーネル時間とユーザー時間の合計です。
Working Setは常駐しているメモリ、Private Bytesは共有されないコミット済みメモリの指標です。
メモリは各サンプルの算術平均で、単位はMiBです。

この条件では試作版のCPU時間とメモリ使用量が少ない結果でした。
CPU消費の絶対量は両版とも小さく、短時間・単一実機の比較です。
旧版は長時間起動済み、試作は新規起動という条件差もあります。
更新タイミング、バックグラウンド負荷、GC、APIの違いにより結果は変動します。
NVAPIを使う旧版とNVMLを使う試作では、GPU取得値の意味や処理内容も完全には同一ではありません。
この測定で長時間動作の安定性やリークがないことまでは判断できません。

## 測定データと再実行

- [全サンプル](performance-samples.csv)
- [集計JSON](performance-summary.json)
- [測定スクリプト](../scripts/measure-processes.ps1)

プロセスIDは現在動作中のものに置き換えてください。
既定では10秒待ってから120秒測定し、target/benchmarks/に保存します。

```powershell
.\scripts\measure-processes.ps1 -LegacyProcessId 20724 -PrototypeProcessId 10900
```

初回の約121秒の測定でも、旧版CPU時間0.671875秒・試作0.343750秒、
平均Private Bytes 46.774 MiB・試作27.062 MiBでした。
最終版の比較結果としては、上の再測定結果を使用します。
